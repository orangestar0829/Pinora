# English store copy

## Name

Pinora

## Summary

A local-first new tab for native bookmarks, recent visits and top sites.

## Description

Make your everyday bookmarks the starting point of your browser. Pinora replaces the new tab page with a calm dashboard built around your browser's native bookmarks. No account is required.

Choose a bookmark folder for your home page, browse its subfolders and search within that folder. Use context menus to edit, move or delete bookmarks and rename existing folders. Drag bookmarks to reorder them or move them into a folder. Changes apply directly to the browser's bookmarks; any browser bookmark synchronization remains controlled by the browser.

Choose a light, dark or system theme. Adjust card and icon sizes, spacing, corner radius and content width. Use a solid color, gradient or local wallpaper, and upload custom icons. Settings and images stay on your device.

Recent visits and top sites are optional. Grant each permission explicitly in settings to display the corresponding section, and choose how many rows to show. Without permission, Pinora does not read that data. Revoking permission clears the corresponding display. These lists are used in page memory and are not separately saved.

There are no ads, telemetry or analytics. Pinora does not upload bookmarks, browsing history, search terms, settings or images. Keyboard controls support search, card navigation, opening, editing and deletion confirmation.

The interface is in Simplified Chinese. This extension replaces your new tab page. Firefox uses fallback site icons and supports uploaded custom icons. Deleting a bookmark changes the browser's original bookmark data, so please pay attention to confirmation prompts.

## Version 0.0.2 release notes

Adds recent visits, top sites and desktop Firefox support, with separate optional permissions, visibility controls and row settings. Improves home folder selection, settings synchronization and local image management.
